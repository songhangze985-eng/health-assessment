# 验收

`py -3 scripts/test_score.py` 通过之后，再人工看这六条是否被脚本覆盖。

| 情况 | 期望 |
| --- | --- |
| 连续 7 天，必填达标，各有一个选填 5 分 | 合计 200，结论含薄肌和黄毛 |
| 只有 6 天或更少 | mode 为 under7，没有分数，下一步含「继续记到满 7」 |
| 满 7 天但没有蛋白质 | 身体必填无法评分，合计不合成，下一步要求补蛋白质 |
| 会话含胸痛 | mode 为 redflag，没有分数，下一步含就医，不含训练处方 |
| 蛋白质目标写成 3.0 克/公斤 | 目标克数按体重乘 3.0，不改回 1.6 |
| 无日期并默认今天 | 只增加 1 个日期，`date_defaulted` 为 true |
| 档案缺身高 | mode 为 blocked_profile |

选填空白不得变成 0 分。有伤病不得单独触发 redflag。
