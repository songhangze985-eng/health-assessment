# health-assessment

个人发展与健康评估技能。一个人一个记忆库。没有文件就打卡，有文件就先抽出记录再入库。满 7 个不同日期之后，脚本给出身体 100、心理抗压 100、合计 200，以及最多三条下一步。

这不是诊断，不开药，不解读影像。薄肌和黄毛只出现在结论文字里，不另开分数栏。

智能体的执行顺序在 [SKILL.md](SKILL.md)。本文件说明仓库里有什么、分数怎么来、记忆库存哪里。

## 一次调用怎么走

1. 询问记忆库的绝对路径。路径写进仓库里的 `.memory-path`，该文件不提交。换一个路径就是另一个人，不能读上一个库。
2. 该路径第一次使用时要一个代号。以后同一路径不再问。
3. 建档必须有身高、体重、年龄、生理性别、训练年限、是否有伤病。缺任何一项就停，不估算。有伤病只作备注，不因此停分。
4. 没有文件就打卡。有文档或表格就把带日期的记录按天写入。整份没有日期时先问算哪一天；说不清则默认今天，并标明日期是默认的。这一天只计 1 天。
5. 把会话交给计分脚本。授予写入后只追加新会话和新报告，不改旧文件。

红旗是胸痛、昏厥、自伤、想自行停药、急性剧痛。出现时先说明就医，本轮不打分，也不给训练建议。

## 分数

身体和心理抗压各 100，合计 200。每一侧都是必填 80、选填 20。

身体必填是蛋白质、抗阻、超负荷，三项均分 80。有克数、组数和重量就用数字对照本人目标；没有数字就退回 1–5，并标明用了哪一种。缺任何一项，这 80 分记为无法评分，不记 0。

心理必填是 1–5 自评分和一条评价分类，各 40。可测量的评价留下并写了行为改变，或明确丢弃人身攻击，分类算完成。可测量的问题被丢掉，或按人身攻击去改计划，这一天的分类记 0。完全没写分类，心理必填无法评分。

选填是 [standards/domains.md](standards/domains.md) 里的其余小项。只在写过的小项之间平分 20。一项都没写，记为无法评分，不记 0。必填项不在选填里再算一次。

不满 7 个不同日期时不出 200 分。回复只保留原始记录，下一步最多两条：继续记到满 7 天；必填有缺口时补上缺口。不给训练动作。

默认目标：蛋白质 1.6 克/公斤（ISSN 2017 的 1.4–2.0 克/公斤之内），抗阻每周 3 次（落在 ACSM 2011 的每周 2–3 天，也满足 2026 年「至少两次」）。用户可以改。改出文献范围仍保存，并在该库的设置日志写明「超出文献范围，按用户自定义计分」。范围和不能写成规则的句子见 [standards/literature.md](standards/literature.md)。

## 记忆库

记忆库在仓库外面。布局：

- `settings/config.json`：代号、档案、当前目标
- `settings/log.jsonl`：每次改标准追加一行
- `sessions/`：一天一条，不覆盖已有文件
- `inbox/`：原文副本
- `analyses/`：脚本输出的报告

## 验收

```bash
py -3 scripts/test_score.py
py -3 scripts/validate_skill.py
```
