# 分析文件

有文档或表格时先走这里，再打分。原文复制到 `inbox/`。

1. 能抽出日期的，按日期写成多条会话。
2. 整份都没有日期：问用户是不是全部算某一天，以及是哪一天。
3. 用户说不清是哪一天：默认今天，`date_defaulted` 设为 true。这一天只计 1 天，不能把一篇文档拆成 7 天。
4. 抽出的蛋白质、组数、重量、评价分类写入对应字段。抽不出的字段留空，不要补假数。
5. 文中出现红旗词时改走 [06-red-flag.md](06-red-flag.md)，不继续打分。

分析报告写入 `analyses/`，内容使用计分脚本的 JSON，不另写一套分数。
